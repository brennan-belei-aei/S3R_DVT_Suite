# tools

Standalone utilities that are not part of the test suite. The GUIs never launch them.

| Tool | Purpose |
|---|---|
| `ParamPorter/` | Enable or disable parameter fields from a CSV template (`param_porter.py --help`). |
| `PulseEyePPTGenerator.py` | Builds PulseEye PowerPoint reports from an external template folder. |
| `omegaSigmaFastDAQPowerPointGenerator.py` | Builds FastDAQ omega/sigma PowerPoint reports. |
